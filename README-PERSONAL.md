# Pixel Agents Personal

Личная визуальная команда для работы с **CodeX** и **Cloudy (Claude)**. Вы создаёте проекты и пишете обычными словами в чат. Команда сохраняет историю, составляет план, выполняет работу, проводит ревью и показывает статус в офисе.

## Что нужно

- Windows 10 или 11.
- [Node.js 20+](https://nodejs.org/).
- Для работы агентов: установленный и авторизованный Codex CLI и/или Claude Code CLI. Интерфейс запускается и без них, но не сможет выполнять задачи агентами.

## Установка для обычного пользователя

1. Скачайте и распакуйте папку `pixel-agents` в постоянное место, например `C:\Apps\PixelAgentsPersonal`.
2. Откройте `Install Pixel Agents Personal.cmd` двойным щелчком.
3. Дождитесь сообщения `Готово`. Установщик создаст ярлык **Pixel Agents Personal** на рабочем столе.
4. В дальнейшем запускайте приложение через этот ярлык или `Start Pixel Agents Personal.cmd`.

Приложение откроется по адресу `http://127.0.0.1:3100/` в отдельном окне браузера. Данные команды хранятся локально в `C:\Users\<ваше-имя>\.pixel-agents\team-workspace.json`.

## Создание первого проекта

1. Откройте приложение и нажмите `+` в заголовке чата.
2. Введите название, например `Мой сайт`.
3. Укажите полный путь к папке проекта, например `C:\Users\<ваше-имя>\Documents\projects\my-site`.
4. Нажмите `Добавить`.
5. Выберите проект слева, напишите задачу простыми словами и нажмите `Создать задачу`.

Пример задачи:

```text
Сделайте страницу контактов, добавьте форму с проверкой полей и проверьте сборку.
```

Команда сначала пишет план, затем исследует проект, выполняет изменения и проводит ревью. Если один агент достигает лимита, второй продолжает с сохранённым контекстом.

## Обновление

Чтобы обновить версию из новой папки приложения, замените файлы и снова запустите `Install Pixel Agents Personal.cmd`. Ваши проекты, задачи и история останутся в локальном хранилище пользователя.

## Устранение проблем

- **Окно не открылось:** откройте `http://127.0.0.1:3100/` в браузере.
- **Сообщение о Node.js:** установите Node.js 20+ и перезапустите установщик.
- **Агенты не работают:** войдите в Codex CLI или Claude Code CLI в обычном терминале; затем перезапустите приложение.
- **Порт 3100 занят:** закройте другое окно Pixel Agents Personal или запустите PowerShell-команду `scripts\start-personal-team.ps1 -Port 3101`.
